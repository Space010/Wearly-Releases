# Wearly – Downloads

Hier liegen die fertigen Versionen von **Wearly**, dem digitalen Kleiderschrank für Android.
Die App arbeitet vollständig offline; alle Daten bleiben auf dem eigenen Telefon.

**Neueste Version:** unter [Releases](https://github.com/Space010/Wearly-Releases/releases/latest) die Datei `wearly-vX.Y.Z.apk`
herunterladen.

## Installation

1. Die APK-Datei auf dem Telefon herunterladen (Browser oder per Datei-Übertragung).
2. Die Datei antippen. Android fragt beim ersten Mal, ob der Browser bzw. die Dateien-App
   **Apps aus unbekannten Quellen installieren** darf: in den angezeigten Einstellungen erlauben,
   zurückgehen und „Installieren“ wählen.
3. Google Play Protect weist unter Umständen darauf hin, dass die App unbekannt ist. „Trotzdem
   installieren“ wählen.

## Updates

Neue Version herunterladen und genauso installieren. Android installiert sie über die vorhandene
App; Kleiderschrank und Outfits bleiben erhalten. Bequemer geht es mit
[Obtainium](https://github.com/ImranR98/Obtainium): diese Seite einmal als Quelle hinzufügen, dann
meldet Obtainium neue Versionen selbst.

## Datensicherung

In Wearly unter **Einstellungen → Sicherung → Exportieren** eine Sicherungsdatei anlegen (z. B.
vor einem Gerätewechsel) und auf dem neuen Telefon unter **Importieren** einlesen.
